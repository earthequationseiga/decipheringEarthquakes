Upload your catalogue

📂

A CSV file with a header row naming the time, longitude, latitude and magnitude columns, in any order.

Common names work, like origin_time, lat, lon, mag. Depth is optional and other columns are ignored. Times without a time zone are read as UTC.

      Events and completeness over time

      Bars: events per 3 months (left axis, log scale). Dots: completeness magnitude Mc (right axis), every 3 months from the 6 months before, by the coefficient-of-variation method of Godano, Petrillo & Lippiello (2023, GJI 236, 994–1001). No dot: fewer than 50 events in that window. Choose a magnitude at or above Mc for the whole period you fit: below it, missing small events look like changes in seismicity.

      Jitter rounded values (off)

      Rounded values put events at exactly the same place or time, which the model reads as extreme clustering. Jitter adds random noise of up to ± the width below, before the cuts. The same seed gives the same noise, so a run can be repeated exactly.

      "Half its last decimal": 129.75 gets ± 0.005°, 129.7 gets ± 0.05° (as R's ETAS package does). A value that happens to end in 0 counts as coarser: 129.0 gets ± 0.5°. The fixed widths start at half the catalogue's most common precision.

      Fit settings

      Each outer iteration re-estimates the background, then the parameters. A good fit usually settles in under 10; if it reports "not converged", more iterations can finish it (each costs about one fit pass).
